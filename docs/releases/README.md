# Release safety reports

One file per version, `v<version>.md`, generated by `scripts/release/report.ts` and
committed by the [Release workflow](../../.github/workflows/release.yml). These files are
history: never edit them. If a report is wrong, fix the script and cut a new release.

## Flow

1. An agent (the `cut-release` skill) or a human runs **Actions → Release →
   Run workflow** (bump: auto/patch/minor/major).
2. The workflow writes the report, a `CHANGELOG.md` entry and the `package.json` version
   to `release/v<x>`, then opens a PR labelled `release` + `needs-human`.
3. `release-guard.yml` fails until the PR has the `release` label, has no `automerge`
   label, includes the report, and has an approval from a **human** reviewer.
4. A human reads the verdict, approves and merges. `release.yml` then tags `v<x>` and
   creates the GitHub Release using the report as its notes.

## What the report checks

| Check               | Flags as attention when                                                                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Commits             | No commits since the last tag                                                                                                              |
| Canvas schema       | `src/persistence/{schema,migrations,share-url}.ts` changed without a version bump, or a bump shipped without a migration and a new fixture |
| Frozen fixtures     | Existing persistence or golden fixtures were modified or deleted                                                                           |
| Pinned golden tests | Hand-verified expectations changed                                                                                                         |
| Snapshot schema     | `SNAPSHOT_SCHEMA_VERSION` changed                                                                                                          |
| Dependencies        | Major version bump of any dependency                                                                                                       |

Informational items: engine source changes, snapshot patches, workflow changes,
non-conventional commits and added/removed dependencies.

Preview locally without writing anything: `npm run release:report`.
